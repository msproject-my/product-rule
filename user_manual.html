How to Use: Product Rule Generator

A step-by-step infographic guide to inputting problem values and automatically generating complete solutions.

Target Problem Example:
$y = x^2 (3x^2 + 1)^5$
1

Choose Question Format / Structure

In the STEP 1: CHOOSE QUESTION FORMAT menu, select the structure matching your problem:

Format Dropdown Menu:
Format 5: $y = x^n (c x^m + d)^q$
Format 5 is perfect for $x^2(3x^2+1)^5$!
2

Enter Question Values

Map out the numbers according to functions $u$ and $v$:

First Function ($u = x^2$) u
x Power ($n$): 2
Second Function ($v = (3x^2 + 1)^5$) v
x Coeff ($c$): 3
x Power ($m$): 2
Constant ($d$): 1
Power ($q$): 5
3

Check "Live Preview"

Ensure the equation in the dark blue box matches your original problem exactly.

$y = (x^2)(3x^2 + 1)^5$
4

Select Display Mode

Choose Full Solution for answers or Blank Worksheet to print practice sheets.

Full Solution (With Answer)
5

Click 'Update Worksheet'

Press the blue button at the bottom left panel to update the notebook paper on the right.

Notebook Worksheet Output

Understanding Full Solution Steps

Lined Notebook Format
Step A

1. Function Identification

$$u = x^2 \quad \text{and} \quad v = (3x^2 + 1)^5$$
Step B

2. First Derivatives

$$\frac{du}{dx} = 2x \quad \text{and} \quad \frac{dv}{dx} = 30x(3x^2 + 1)^4$$
Step C

3. Substitution Into Product Rule Formula

$$\frac{dy}{dx} = v \frac{du}{dx} + u \frac{dv}{dx}$$
$$= (3x^2 + 1)^5 \cdot (2x) + (x^2) \cdot \left(30x(3x^2 + 1)^4\right)$$
